# FatGoats Studios — Functional Specification

## Overview
FatGoats Studios is an all-in-one digital operating system for film, television, animation, and indie creator studios.

## Feature Modules
1. **Project Dashboard**: KPI cards, countdown for embargoed scenes, season/episode progress bars, action bar, sync monitor.
2. **Scripts & Screenplay Suite**: Fountain markdown parser & renderer, embargo lock countdown, character auto-linking, in-scene voice memos, teleprompter mode, script analytics.
3. **Character Continuity & Dossiers**: Bio/demographics, visual gallery, voice archive audio recorder/player, global mentions matrix, linked crew.
4. **Creative Whiteboard & Moodboard**: Infinite canvas, pan & zoom, sticky notes, moodboard images, narrative cards, connector arrows, multi-board lock/pin.
5. **Storyboard Sequence Builder**: Shot-by-shot sequence frames, camera framing & movement, director notes, dialogue, episode binding, drag/reorder.
6. **Team Communication Hub**: Real-time channels & DMs, voice notes, script snippets, whiteboard coordinate pins, polls, soundboard attachments, scheduled messages, scratchpads, read receipts.
7. **Tasks & Production Kanban**: Custom columns, character tagging, deadlines, overdue warnings, assignee/episode filters.
8. **Asset & Media Vault**: Virtual directory tree, file previews, tags, version tracking, deep linking.
9. **Show Soundboard**: Categorized sound banks, live microphone recording, waveform controls, 1-click chat share.
10. **Lore & Worldbuilding Bible**: Series bible, custom key-value property cards, asset vault embeds, tags, emoji headers.
11. **Project Timeline & Milestones**: Phase roadmaps (Scripting, Casting, Production, Post, Distribution), status badges, deadlines.
12. **Team Directory & Profiles**: Cast/crew profiles, avatars, banners, timezones, live availability emojis, linked characters, 1-click DM.
13. **System Admin & Security**: Setup wizard, RBAC, invite code generator, full ZIP workspace export/import.
